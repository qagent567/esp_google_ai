# 🤝 Руководство по участию в разработке (Contributing Guide)

Мы рады любому вкладу в развитие **GeminiESP32**! Если вы хотите предложить новую функцию, исправить баг или улучшить документацию, следуйте этой инструкции.

---

## 🛠️ Как внести свой вклад

1. **Форкните репозиторий**:
   ```bash
   git clone https://github.com/qagent567/esp_google_ai.git
   ```

2. **Создайте ветку для ваших изменений**:
   ```bash
   git checkout -b feature/awesome-new-feature
   # или
   git checkout -b fix/bug-description
   ```

3. **Соблюдайте правила разработки**:
   - 🔒 **Безопасность памяти**: ESP32 имеет ограниченный объем RAM. Избегайте частых динамических аллокаций (`malloc`/`new`) в цикле `loop()`.
   - 🧩 **Модульность**: Новые крупные функции должны поддерживать флаги условной компиляции в `GeminiConfig.h` (`#if GEMINI_ENABLE_...`), чтобы не раздувать Flash память базовых прошивок.
   - 🌐 **Обратная совместимость**: Не ломайте существующие сигнатуры публичных методов `GeminiESP32`.
   - 📝 **Комментарии**: Добавляйте понятные Doxygen-комментарии к новым методам и структурам.

4. **Проверьте сборку примеров**:
   Убедитесь, что все примеры компилируются без ошибок:
   ```bash
   pio ci --board=esp32dev --lib=lib/GeminiESP32 lib/GeminiESP32/examples/BasicChat/BasicChat.ino
   pio ci --board=esp32cam --lib=lib/GeminiESP32 lib/GeminiESP32/examples/Vision_ESP32_CAM/Vision_ESP32_CAM.ino
   ```

5. **Отправьте Pull Request**:
   - Опишите внесенные изменения и причину их добавления.
   - Укажите, на каком реальном железе проводилось тестирование (напр., ESP32-WROOM-32, ESP32-S3, ESP32-CAM).

---

## 🐛 Сообщение об ошибках (Issues)

Если вы обнаружили баг:
- Укажите версию библиотеки (`GeminiESP32::getVersion()` или номер релиза).
- Опишите используемую плату и версию ядра ESP32 Arduino Core (напр., v2.0.14 или v3.0.x).
- Приложите минимальный воспроизводимый пример кода и лог Serial Monitor.
