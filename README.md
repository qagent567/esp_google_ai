[![License](https://img.shields.io/badge/License-CC_BY--NC_4.0-yellow.svg)](LICENSE)

Универсальный Open-Source проект для интеграции искусственного интеллекта **Google Gemini** в микроконтроллеры **ESP32** с поддержкой Smart DNS (работа без VPN), управления периферией (GPIO/ADC/I2C), нативного Function Calling, компьютерного зрения (ESP32-CAM) и встроенного Web Dashboard.

## ⚡ 1. Быстрый тест: Готовая CLI-прошивка (`src/`)

Если вы хотите **мгновенно протестировать** работу Gemini на ESP32 без написания кода:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/qagent567/esp_google_ai.git
   ```
2. Откройте проект в **VS Code + PlatformIO** и нажмите **Upload** (➡).
3. Откройте **Serial Monitor** на скорости `115200` бод.
4. Введите команду `wizard` для пошаговой настройки Wi-Fi и API-ключа!

### Доступные команды CLI:
| Команда | Описание |
|---|---|
| `wizard` | Пошаговый мастер первоначальной настройки |
| `ask <вопрос>` | Задать вопрос искусственному интеллекту |
| `models` | Сканировать и вывести список доступных моделей Gemini |
| `status` / `telemetry` | Вывести статус памяти RAM, аптайм и состояние квот |
| `demo automation` | Демонстрация выполнения аппаратных действий платой |

## 📦 2. Автономная библиотека: `GeminiESP32` (`lib/GeminiESP32/`)

Если вы создаете **свой собственный проект** (умный дом, робот, метеостанция, камера) — используйте библиотеку [`lib/GeminiESP32`](lib/GeminiESP32/README.md).

### Как подключить к своему проекту:
* **PlatformIO**: Скопируйте папку `lib/GeminiESP32` в папку `lib/` вашего проекта и добавьте в `platformio.ini`:
  ```ini
  lib_deps = bblanchon/ArduinoJson @ ^7.0.4
  ```
* **Arduino IDE**: Скачайте папку `lib/GeminiESP32` и добавьте через **Скетч → Подключить библиотеку → Добавить .ZIP библиотеку**.

### Пример использования в 3 строки:

```cpp
#include <WiFi.h>
#include <GeminiESP32.h>

GeminiESP32 ai("ВАШ_API_КЛЮЧ", "gemini-3.5-flash-lite");

void setup() {
    Serial.begin(115200);
    WiFi.begin("SSID", "ПАРОЛЬ");
    while (WiFi.status() != WL_CONNECTED) delay(500);

    ai.begin(); // Автоматически настраивает Smart DNS и квоты

    String answer = ai.ask("Как помигать светодиодом на ESP32?");
    Serial.println(answer);
}

void loop() {}
```

## 🌟 Продвинутые возможности библиотеки `GeminiESP32`

1. 👁️ **Gemini Vision (ESP32-CAM)**: Отправка фото с камеры OV2640 для распознавания объектов и текста.
2. ⚙️ **Нативный Function Calling**: Регистрация C++ функций с типизированными аргументами, которые ИИ вызывает самостоятельно.
3. 🌐 **Встроенный Web Dashboard**: Локальный веб-интерфейс чата и телеметрии прямо в браузере телефона по Wi-Fi.
4. 🌊 **SSE Streaming**: Мгновенный посимвольный вывод ответа по мере его генерации серверами Google.
5. 🚀 **FreeRTOS Async**: Фоновое выполнение запросов на Ядре 0 — цикл `loop()` никогда не блокируется.
6. 🧠 **NVS Память**: Сохранение контекста переписки во Flash-память между перезагрузками.
7. 🛡️ **Изоляция пинов**: Белый список GPIO защищает другие датчики и экраны вашей прошивки.
8. 🧩 **Полная модульность**: Любой компонент можно отключить через `#define` в `GeminiConfig.h`, экономя память Flash.

👉 **[Подробная документация и 8 готовых примеров в папке lib/GeminiESP32 →](lib/GeminiESP32/README.md)**

## 🌐 Smart DNS (Работа из РФ без VPN)

Google AI Studio блокирует прямые запросы с российских IP. В проект встроена автоматическая поддержка технологии **Smart DNS** ([xbox-dns.ru](https://xbox-dns.ru/)):
* `111.88.96.50` (Primary)
* `111.88.96.51` (Secondary)

Запросы к доменам Google прозрачно перенаправляются через безопасный SNI-шлюз на уровне `lwIP`, обеспечивая максимальную скорость и прямой доступ без VPN.
