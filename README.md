# ESP32 + Google AI Studio (Gemini) с обходом блокировок РФ

Прошивка для микроконтроллера **ESP32**, позволяющая отправлять запросы и получать ответы от нейросетей Google Gemini (**Google AI Studio API**) напрямую из Российской Федерации без использования сторонних серверов и VPN.

---

## 🚀 Как это работает (Обход блокировок из РФ)

Google AI Studio API (`generativelanguage.googleapis.com`) блокирует прямые запросы с российских IP-адресов. 

В данной прошивке используется технология **Smart DNS** от сервиса [xbox-dns.ru](https://xbox-dns.ru/):
- **Основной DNS**: `111.88.96.50`
- **Дополнительный DNS**: `111.88.96.51`

При подключении к Wi-Fi прошивка ESP32 на уровне сетевого стека `lwIP` настраивает использование этих DNS-серверов. Smart DNS автоматически направляет запросы к доменам Google через прозрачный SNI-шлюз, что позволяет ESP32 делать стандартные HTTPS-запросы к официальному API Google без потери скорости и без лишней нагрузки на микроконтроллер.

## ⚙️ Возможности прошивки

- 🔑 **Интерактивный CLI в Serial-мониторе**: удобная настройка Wi-Fi сети и API-ключа прямо через терминал без необходимости перепрошивки платы.
- 💾 **Безопасное сохранение во Flash (NVS)**: параметры (SSID, API-ключ, модель, DNS, промпты) сохраняются во Flash **только после успешного подключения** к сети. Пароль от Wi-Fi хранится **только в RAM** активной сессии до перезагрузки.
- 🛑 **Мгновенная отмена поиска Wi-Fi по клавише `e`**: при поиске сети или вводе пароля нажатие клавиши `e` мгновенно прерывает подключение и возвращает в CLI.
- 🧙‍♂️ **Пошаговый мастер настройки (`wizard`)**: легкий старт при первом включении и запрос пароля сессии при перезагрузке.
- 🤖 **Поддержка актуальных моделей Gemini**: `gemini-2.0-flash`, `gemini-1.5-flash`, `gemini-2.5-flash` и др.
- 🛡️ **Оптимизация памяти (Heap Guard)**: потоковый фильтр `ArduinoJson 7` для парсинга ответов без риска переполнения кучи (RAM).
- 🔄 **Offline-First & Auto-Reconnect**: автоматическое восстановление Wi-Fi соединения при обрывах связи.

## 📦 Быстрый старт

### 1. Получение API-ключа Google AI Studio
1. Перейдите на [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Создайте новый API-ключ (Get API key).

### 2. Сборка и прошивка через PlatformIO
1. Откройте проект в VS Code с установленным расширением **PlatformIO IDE**.
2. Подключите плату ESP32 через USB (порт `COM10`).
3. Нажмите кнопку **Build** (✔) и затем **Upload** (➡).
4. Откройте **Serial Monitor** на скорости `115200` бод.

## 💻 Справочник команд CLI (Serial Monitor)

После открытия Serial-монитора (115200 бод) доступен интерактивный интерфейс командной строки:

| Команда / Клавиша | Описание |
|---|---|
| Клавиша `e` / `E` | Мгновенно остановить поиск / подключение к Wi-Fi сети |
| `wizard` | Запустить пошаговый мастер полной настройки (Wi-Fi + API Key) |
| `setup wifi` | Интерактивная настройка Wi-Fi с проверкой подключения |
| `setup ai` | Интерактивная настройка только параметров нейросети |
| `models` / `scan models` | Сканировать и вывести список доступных моделей Gemini через API |
| `demo automation` | Демонстрация использования Gemini AI в программном коде ESP32 |
| `connect` | Подключиться к Wi-Fi с текущими параметрами (нажмите `e` для отмены) |
| `disconnect` | Отключиться от Wi-Fi |
| `set ssid <имя_сети>` | Установить SSID точки доступа Wi-Fi в сессии |
| `set pass <пароль>` | Установить пароль от Wi-Fi в RAM текущей сессии |
| `set key <api_key>` | Установить API-ключ Google AI Studio (сохраняется во Flash) |
| `set model <модель>` | Сменить используемую модель Gemini (по умолчанию `gemini-2.0-flash`) |
| `set prompt <текст>` | Установить системный промпт (роль/инструкцию ассистента) |
| `set tokens <1-8192>` | Задать максимальное количество токенов в ответе (по умолчанию 1024) |
| `set temp <0.0-2.0>` | Задать температуру генерации (по умолчанию 0.7) |
| `set dns <ip1> [ip2]` | Задать кастомные DNS серверы (по умолчанию `111.88.96.50 111.88.96.51`) |
| `scan` | Сканировать окружающие Wi-Fi сети с отображением RSSI и шифрования |
| `connect` | Подключиться к Wi-Fi с текущими сохраненными параметрами |
| `disconnect` | Отключиться от текущей Wi-Fi сети |
| `status` / `info` | Вывести текущий статус подключения, IP, DNS, модель и объем свободной RAM |
| `test` | Отправить короткий проверочный запрос в Gemini API |
| `ask <вопрос>` | Отправить вопрос к Gemini AI |
| `<любой текст>` | Если просто ввести текст вопроса, он будет автоматически отправлен в Gemini |
| `save` | Принудительно сохранить текущие настройки во Flash-память (NVS) |
| `reset` | Сбросить настройки к заводским значениям |
| `reboot` | Перезагрузить плату ESP32 |
| `help` / `?` | Показать список доступных команд |

## 🛠️ Структура проекта

```text
esp_google_ai/
├── include/
│   ├── CLI.h              # Заголовок интерактивного интерфейса командной строки

│   └── main.cpp           # Главный цикл setup() и loop()
├── platformio.ini         # Конфигурация сборщика PlatformIO
├── .gitignore             # Исключение артефактов компиляции
└── README.md              # Документация проекта
```
